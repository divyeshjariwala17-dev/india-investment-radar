USE THIS FILE FIRST
-------------------
RUN_THIS_ONLY_7_0_0_FULL_RELIABILITY_PREMIUM.bat

WHAT 7.0.0 LOCKS
----------------
• All previously agreed modules remain available.
• Daily Recommendations is the default opening decision page.
• Stock cards show Current / Entry / Targets / potential ₹ + % / Stop / downside ₹ + % / R:R / duration / confidence where applicable.
• Mutual Funds, Fixed Income, IPO, Gold/Silver, Crypto and Other Investments use the fields appropriate to each product instead of inventing stock-style fields.
• I HAVE MONEY TODAY is available directly on Daily Recommendations.
• Full Best Use of My Money and Go by Segment remain available.
• The Other Investments master universe includes FD/RD, Small Finance Bank/NBFC deposits, Post Office products, PPF/NSC/KVP/SCSS/Sukanya, T-Bills/G-Secs/SDL, retirement products, REIT/InvIT, international, real estate and alternatives/manual-review assets.
• Daily Update visibly shows each running step and PASS/WARNING/FAIL status.
• A failed optional source does not silently erase valid local cache.
• Free-first source registry + no automatic paid upgrade/spend policy are included.
• UI theme/background/density/default page are configurable without code.
• Mobile-responsive layout is included.
• Same-Wi-Fi phone launcher is included.
• Docker/GitHub web-deployment package is included for an online server.

NORMAL DAILY USE
----------------
1. Open the Desktop shortcut: India Investment Radar.
2. If you need the latest data, press DAILY UPDATE.
3. Watch the live update progress until it finishes.
4. Open Daily Recommendations.
5. Reverify an important final transaction with another trusted source before committing money.

FIRST INSTALL
-------------
• Python 3.11+ must already be installed.
• Internet is needed during the first install for Python packages and whenever external market data must be refreshed.
• The installer preserves existing Radar data/backups during an upgrade.
• After verification it creates the normal Desktop/Start Menu shortcut automatically.

PHONE — SAME WIFI
-----------------
Use the shortcut:
India Investment Radar - Phone Same WiFi

The PC must remain ON for this mode. The launcher displays the phone URL.

ANYWHERE ACCESS WITH PC OFF
---------------------------
Use the WEB_DEPLOY folder on an always-on online server/VM.
The app is Docker-ready and uses a persistent /radar-data volume when deployed with the included docker-compose file.

No cloud provider can be honestly guaranteed to remain free forever. The software is provider-portable so the server can be moved without redesigning the Radar.

TRUST RULE
----------
The software must not invent fresh data or guaranteed future returns.
Critical stale/missing data must downgrade or block an actionable call.
Market recommendations remain probabilistic even when formulas/data checks pass.

SAFE REMOVAL
------------
Use UNINSTALL_RADAR_SAFE.bat from this package if you ever want to remove the local installation.
